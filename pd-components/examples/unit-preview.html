<pd-unit> — TypeScript code-unit outline

Built around the three things a reviewer checks first when a new class lands: what is it called, what does it depend on, and what is its public surface. Bodies are omitted by design.

A service class

Shared connection pool; one round-trip per check. Wall-clock, swapped for a fake in tests. Window size + per-key ceilings, hot-reloaded. Core check — true if the key is under budget for the current window. Tokens left without consuming one. Clears a key's window — admin/test escape hatch. Configured window length, exposed for the Retry-After header.

An interface (no constructor deps)

An abstract base with lineage

Owns the transaction lifecycle for subclasses. Structured, request-scoped. Subclass declares its table. Run fn inside a transaction; rolls back on throw. Drains the pool.
