We need per-client rate limiting at the gateway before opening the partner program. - Given a client that has used its request budget for the window - When it sends one more request - Then the gateway responds `429` with a `Retry-After` header - Given clients on the free and partner plans - When both exceed the free-plan limit - Then only the free-plan client is throttled Token-bucket limiter as gateway middleware, backed by Redis (one bucket per client key).
