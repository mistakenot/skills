## Cross-Cutting Themes

Before the per-skill breakdown, three systemic patterns account for the majority of issues:

1. **Workflow overview duplication** — Every skill inlines the full pipeline ASCII diagram from `references/workflow-overview.md`. This should be linked, not copied. (~13 of 14 skills affected)
2. **Reference file content inlined** — Most skills copy-paste their reference files (templates, conventions, formats) verbatim into SKILL.md instead of linking to them. This defeats progressive disclosure and creates maintenance drift. (~10 skills affected)
3. **Description not in third person** — Most descriptions start with "Use when the user..." which is an imperative directed at the agent. Descriptions should lead with what the skill does in third person, then append trigger conditions. (~10 skills affected)

**Recommended global fixes:**
- Remove all inline workflow overview blocks; replace with `See [references/workflow-overview.md](references/workflow-overview.md)`
- Remove all inline reference content; replace with links to the corresponding `references/` files
- Rewrite all descriptions to lead with a third-person functional summary
